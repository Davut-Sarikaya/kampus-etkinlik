# Kampüs Etkinlikleri - Sprint 2

Bu proje, "Kampüs Etkinlikleri" uygulamasının CSS giydirilmiş ve mobil uyumlu (responsive) hale getirilmiş ikinci sürümüdür[cite: 2]. Sprint 1'deki HTML iskeleti bozulmadan, CSS Grid yapısı kullanılarak sayfaların hem telefonda hem de geniş ekranlarda düzgün ve taşmadan görünmesi sağlanmıştır[cite: 2]. 

## 🚀 Proje Özellikleri
* **Responsive Tasarım:** Mobil cihazlarda tek sütun, geniş ekranlarda çoklu sütun (Grid) düzeni[cite: 2].
* **Kişiselleştirilmiş Tema:** CSS'teki `--no` değişkenine girilen öğrenci numarası üzerinden matematiksel formülle (mod 360) benzersiz bir renk paleti (HSL) üretilmiştir[cite: 2].
* **Kart Yapısı:** Önceki sprintte kullanılan tablolar kaldırılarak `<article>` tabanlı modern kart tasarımına geçilmiştir[cite: 2].
