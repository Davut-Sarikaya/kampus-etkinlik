# Kampüs Etkinlikleri - Sprint 3 (JavaScript ve DOM)

Bu proje, "Kampüs Etkinlikleri" web uygulamasının JavaScript modülleriyle canlandırıldığı, dinamik hale getirildiği ve form doğrulama mekanizmalarıyla güçlendirildiği üçüncü sürümüdür.

## 🚀 Proje Özellikleri ve Teknolojiler
* **JavaScript ES Modülleri (`import/export`):** Veriler (`data.js`) ve fonksiyonlar ayrı modüler dosyalarda yönetilmektedir.
* **Dinamik İçerik Üretimi:** Ana sayfa ve etkinlikler listesindeki kartlar HTML içine elle yazılmak yerine JavaScript ile veritabanından dinamik olarak üretilmektedir.
* **Arama ve Kategori Filtreleme:** Kullanıcılar etkinlikler sayfasında anlık olarak arama yapabilir ve kategorilere göre filtreleme gerçekleştirebilir.
* **Dinamik Detay Sayfası:** URL'deki parametre (`?id=...`) okunarak tek bir şablon sayfa üzerinden (`etkinlik-detay.html`) ilgili etkinliğin bilgileri ve PNG afişleri ekrana yansıtılır.
* **Form Doğrulama ve JSON Çıktısı:** Ekleme ve güncelleme formlarında HTML5 validasyonları ve özel JavaScript hata yönetimi (`novalidate`) uygulanmıştır. Hatalı durumlarda uyarılar gösterilirken, başarılı gönderimde veriler konsola ve ekrana JSON nesnesi olarak basılır.
* **Kişiselleştirilmiş Tema:** Öğrenci numarası (`2416501057`) üzerinden HSL renk paleti ve Palatino font ailesi kullanılmıştır.
